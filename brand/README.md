# Official Retium logos

Four variants, all **monochrome** (verified by pixel sampling — no saturated colour
in any of them).

| File | Dimensions | Ink | Use on |
|---|---|---|---|
| `retium-logo-horizontal-onlight.png` | 573×106 | dark (brightness 48) | light backgrounds |
| `retium-logo-horizontal-ondark.png` | 573×106 | light (brightness 236) | dark backgrounds |
| `retium-logo-vertical-onlight.png` | 415×212 | dark (brightness 48) | light backgrounds |
| `retium-logo-vertical-ondark.png` | 415×212 | light (brightness 236) | dark backgrounds |

`onlight` = the variant that goes **on** a light background (dark ink).
`ondark` = the variant that goes **on** a dark background (light ink).

Original filenames from the owner were `Retium_basic.png` (→ horizontal onlight),
`Retium_inverted.png` (→ horizontal ondark), `Retium_vertical.png` (→ vertical onlight)
and `Retium_vertical_inverted.png` (→ vertical ondark). They were renamed on import so
the intended background is unambiguous.

See `../IMAGE_PROMPT.md` for placement rules.
