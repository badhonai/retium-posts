## PART 10: RETIUM TECHNICAL REFERENCE

### Verified Facts (From Official Sources)

**Architecture:**
- Layer-1 blockchain built from scratch in Rust
- Not a fork or copy of any existing chain
- PrimeMesh multi-dimensional mesh structure
- Block positions determined by prime-number factorization (PNLA)
- Block 15 = 3 × 5, links to blocks 3 and 5
- Multiple blocks process simultaneously
- No mempool (transactions go directly to Router)
- If a block doesn't fit PrimeMesh, it's rejected

**Execution:**
- Router directs transactions into PrimeMesh
- Matchmaker assigns 5-Worker quorum per transaction
- Assignment is deterministic but unpredictable
- Workers independently execute and validate
- Matching approval establishes transaction-level finality
- Suits verify and push to HardFinal (irreversible)
- Keepers maintain mesh topology and state routing

**Validator Tiers:**
- Workers: 10,000 RTM minimum stake, execution
- Suits: 100,000 RTM minimum stake, finality
- Keepers: 1,000,000 RTM minimum stake, topology

**Reward Distribution (per finalized block):**
- 90% → Workers
- 5% → Foundation
- 3% → Keepers
- 1% → Protocol Burn
- 0.5% → Suits
- 0.5% → Treasury

**Tokenomics:**
- $RTM: fixed supply 1 billion, 0% inflation
- No minting beyond genesis
- No token allocation (no team, no VCs, no advisors)
- $Pie: staking token, minted 1:1 when staking RTM, burned when unstaking
- Safehouse: 1 rUSD → 1 RTM, 1 RTM → 1 rUSD
- Validator rewards from real transaction fees only

**Fees:**
- Weight-based: Weight 1 ($0.01) to Weight 5 ($0.45)
- USD-denominated, converted to RTM via oracle rate
- No gas auctions, no bidding wars
- Optional priority credits: +10% Level 1, +20% Level 2

**Smart Contracts:**
- WASM-based execution
- Write in Rust, AssemblyScript, or C
- Unified Contract Layer (single model for tokens, DAOs, NFTs, DeFi)

**Current Status:**
- Public testnet live
- NFT Launchpad available
- Wallet Connect live
- Early Validator Round: $100 Worker / $1,000 Suit (permanent seats)
- Post-mainnet: $1,000 Worker / $10,000 Suit
